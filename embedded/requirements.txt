# Fully pinned dependency closure for the embedded interpreter.
#
# WHY THIS FILE EXISTS
# --------------------
# These packages get baked into the shipped binary, and the install
# runs with --upgrade, so an unconstrained name here means the artifact
# is built from whatever PyPI happens to serve that day. That is not
# hypothetical: `mcp` was unpinned when 2.0.0 deleted the entire
# mcp.server.fastmcp subpackage, and because tai_runtime/server.py
# opens with `from mcp.server.fastmcp import FastMCP`, release builds
# produced a binary that compiled and linked cleanly and then died at
# startup with ModuleNotFoundError. It went unnoticed for ~2 months:
# a dev tree's build/site-packages is populated once and guarded by
# $(SITE_PKGS)/.stamp, so only a fresh resolve -- i.e. CI -- ever hits
# the new version.
#
# Transitive deps are pinned too, not just the six direct ones. Pinning
# only the direct names still lets pydantic, anyio, starlette et al.
# float, which is the same failure mode one level down.
#
# INTERACTION WITH THE UNIVERSAL2 FUSE STEP
# -----------------------------------------
# These pins are the *starting point*, not necessarily what ships. The
# release workflow's "Fuse single-arch native extensions to universal2"
# step scans installed .so files with lipo and, for any that are not
# universal2, swaps in a pure-Python wheel or fuses arm64+x86_64 wheels
# via delocate-merge -- falling back to an older version when the
# pinned one has no x86_64 wheel. So cffi/cryptography in particular
# may end up at a lower version than pinned here. That is by design;
# pinning just makes the input deterministic.
#
# REGENERATING
# ------------
# Bump a version deliberately, then re-resolve and verify:
#
#   make -C embedded deps-clean
#   make -C embedded deps HOST_PYTHON=/path/to/python3.13
#   .../python3.13 -c "from mcp.server.fastmcp import FastMCP"
#
# Versions below are the closure resolved by the green v0.1.0a39
# release build (run 31838563514), which passed the CI smoke test with
# 26 tools registered over a real MCP initialize + tools/list roundtrip.
